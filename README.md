# YSU Title Page Template

---

## Հայերեն

Այստեղ կարող եք գտնել ԵՊՀ ավարտական աշխատանքի տիտղոսաթերթի ձևանմուշը երկու տարբերակով՝

- **LaTeX / Overleaf տարբերակ**՝ `main.tex`
- **Microsoft Word տարբերակ**՝ `ԵՊՀ_Տիտղոսաթերթ.docx`

Ձևանմուշը պատրաստված է ԵՊՀ-ի պահանջների հիման վրա։ Պահանջները կարող եք տեսնել `karg-1-4.pdf` ֆայլում։

Օգտագործելուց առաջ ցանկալի է ստուգել ձեր ամբիոնի կամ ղեկավարի հետ։

## Русский

Здесь вы можете найти шаблон титульного листа выпускной работы ЕГУ в двух форматах:

- **LaTeX / Overleaf версия**: `main.tex`
- **Microsoft Word версия**: `ԵՊՀ_Տիտղոսաթերթ.docx`

Шаблон сделан на основе требований ЕГУ. Требования можно посмотреть в файле `karg-1-4.pdf`.

Перед использованием лучше проверить шаблон у вашей кафедры или научного руководителя.

## English

Here you can find the YSU thesis title page template in two formats:
